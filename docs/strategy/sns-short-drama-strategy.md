## 1. 市場リサーチ

### 1-1. 市場規模と成長

- 国内ショートドラマ市場は2026年に約1,530億円へ拡大する予測。年間映画興行収入（2,000〜2,500億円）の6〜7割に相当する規模（CREAVE予測、Branc / PR TIMES）。
- 動画広告市場は2026年に初の1兆円超え、縦型動画のシェアが急拡大（Branc）。
- GOKKO（ごっこ倶楽部）はシリーズBで約11億円を調達（JAFCO、日本テレビ等）。累計再生100億回超、SNS総フォロワー560万人超。
- HA-LU（Z世代向けレーベル）が資金調達、年500話以上を制作。
- 日本テレビ、テレビ東京がショートドラマ制作を強化、テレ東はBUMPでオリジナル配信（日経クロストレンド）。
- BUMP（emole）は世界100ヶ国・地域へ展開。クリエイターには有料話数の35%を還元。

**示唆:** 資本が入り、テレビ局が参入し、市場が「量産期」に入っている。中小企業向けの発注は今後2〜3年で「普通のこと」になり、価格競争が起こる。**先行して「型」と事例を持つ者が勝つ**局面。

### 1-2. 視聴者データ

- 認知度91.6%、視聴経験75%（ガイアックス調査、2026年5月）。
- 視聴媒体はTikTok 42.4%でYouTube・Instagramを上回る。
- TikTok国内4,200万人超。10〜30代が65.5%だが40〜50代の利用が拡大中。
- リールの最適尺は2024年の30秒から、2026年は15〜20秒のテンポ重視に短縮傾向（SNS運用代行各社）。
- 冒頭3秒で30〜50%が離脱、15秒でさらに20%、30秒でさらに15%離脱（0120.co.jp）。

**示唆:** 「認知はもう済んでいる」市場。企業の関心は「ドラマ形式が有効か」ではなく「うちの業種で成果が出るか、いくらで、誰が作るか」に移っている。

### 1-5. 法規制・炎上リスク

- 法務省が2026年7月27日、生成AIによる肖像・声の無断利用（パブリシティ権侵害）に関する指針を公表。
- 経産省・総務省「AI事業者ガイドライン」第1.2版（2026年3月31日）。日本ではAI生成表記は法的義務なし（自主的取組）。
- EU AI法は2026年8月2日からAI生成コンテンツの透明性義務。海外配信時は表記必須。
- 日本俳優連合は声の肖像権確立を提言。実演家の声・演技のAI利用には同意・利用範囲・期間・対価の契約明記を要求。
- 炎上事例: ウテナ「潤い戦士 モイスチャー」（全編AIアニメ、批判で取り下げ）、マクドナルドAI広告（「気持ち悪い」反応）、伊藤園AIタレントCM（話題化と賛否）。原因は「不気味の谷」と「ブランドとの不適合」。

**示唆:** AI軸は「開示ポリシー」「実在人物・作品名をプロンプトに使わない」「実写俳優のAI学習利用は契約で明示」の3点を商品仕様に組み込むこと。これは競合との差別化にもなる（大手ほど法務が厳しく、対応済みの制作会社を選ぶ）。

### 2-3. 顧客が失敗する理由（＝差別化の根拠）

業界記事で共通して挙がる失敗要因は次の4つ。

1. 縦型フォーマットの理解不足（横型の流用、テロップ設計なし、推奨尺無視）
2. 単発で終わり、シリーズ化・継続投稿をしない
3. マーケ視点（ターゲット・配信・効果測定）のない「作って終わり」
4. 低価格帯での品質不足

**したがって、あなたのサービスの差別化は「価格」ではなく次の3点に置く。**

- **型化された脚本**（3秒フック、登場人物3人まで、60〜90秒、CTA設計）
- **シリーズ前提の設計**（キャラクターと世界観を先に固め、話数で売る）
- **運用込み**（投稿・分析・フックABテストまで含める）

### 2-4. ポジショニング

> **「中小企業のための、シリーズ前提ショートドラマ工房」**
> 大手レーベルには小さすぎ、量産屋には物足りない案件を、AI×実写の2軸で月額運用まで請け負う。

### 4-2. 軸ごとの得意用途

**AI軸が向く案件**

- 士業・保険・金融・不動産の「制度説明あるある」（俳優不要、コンプラ表現の修正が容易）
- BtoB・SaaSの課題ストーリー（抽象的な商材）
- 多言語・インバウンド向け（1本から翻訳展開）
- 毎日投稿のアカウント運用（原価が低く量が出せる）
- 顔出しNGの業種

**実写軸が向く案件**

- 採用（社員の顔、職場の空気が主役）
- 飲食・美容・小売（実物・実店舗が魅力）
- 地域・観光（ロケそのものが価値）
- 「AI感」がブランド毀損になる高級・食品・医療

## 5. 収益モデルと月商500万円の分解

### 5-1. 12ヶ月目の月商構成

| 区分 | 顧客 | 数量 | 売上 |
|---|---|---|---|
| 実写 継続A | 月額スタンダード | 4話 | 130万 |
| 実写 継続B | 月額スタンダード | 4話 | 130万 |
| 実写 スポット | 4話パック | 4話 | 108万 |
| AI 継続 ×3社 | 月額AIライト | 12話 | 114万 |
| AI スポット | 6話パック 0.5本 | 3話 | 27万 |
| 運用・広告・オプション | 3社 | | 30万 |
| **合計** | **継続5社＋スポット2〜3社** | **実写12話 / AI15話** | **約540万** |

- 撮影日: 月3日（キャパは月6〜8日まで拡張可能）
- AIオペ: 15話 × 4〜5h = 60〜75h → 業務委託1名
- 粗利: 実写約65%、AI約55%、運用約70% → **全体で約60%、月次粗利約320万**
- 固定費（自分の役員報酬、ディレクター1名、ツール、オフィス）を100〜150万と置いても営業利益150万超

### 5-2. 継続比率が鍵

月額契約が月商の70%以上（上表では約69%）。スポット依存だと毎月ゼロから営業することになり、月商500万は「良い月だけ」になる。**6ヶ月目以降は新規案件を原則パックか月額でしか受けない**運用にする。

### 5-3. 必要リード数

- 月の新規受注: 3〜4件（継続の解約補填込み）
- 成約率25%と置くと商談14件/月、リード30〜40件/月
- 内訳目安: 自社SNS経由10、紹介・パートナー10、アウトバウンド10、SEO・料金ページ5〜10

### 5-4. 業界ベンチマーク

映像・音声・文字情報制作業の売上総利益率は42.7%（リスクモンスター業界レポート）。上記モデルは「顧客施設ロケ」「まとめ撮り」「AIによる脚本・生成の効率化」で60%を狙う設計であり、業界平均より高い分、**単発・小ロットを受けない規律**が前提。

## 6. 集客・営業戦略

### 6-1. 自社アカウントを「ショーケース」にする（最重要）

GOKKO、HA-LU、ムービーインパクト、ナイトてんしょん、いずれも自社コンテンツかSEO記事で集客している。制作会社にとって自社アカウントは最強の営業資料。

- **AIドラマを毎日1本投稿**（原価6,000〜1万円/本で回せる。AI連続投稿型で3ヶ月10万フォロワーの事例あり）
- **実写ドラマを週1本**（パイロット顧客の案件を許諾を得て公開、または自社オリジナル）
- テーマは「中小企業あるある」「採用あるある」など、そのまま顧客の業種に横展開できるもの
- KPI: 3ヶ月で1万フォロワー、6ヶ月で「この会社に頼みたい」DMが月10件

### 6-2. パートナー・紹介（最も成約率が高い）

| パートナー | 提供価値 | 条件 |
|---|---|---|
| SNS運用代行会社 | ドラマ制作をOEM卸（AI 7万、実写 22万） | 白ラベル可、月最低話数 |
| 採用コンサル・求人媒体代理店 | 「採用ドラマ」パッケージの共同提案 | 紹介料10% |
| 税理士・社労士・商工会議所 | 補助金セットで提案 | 申請サポート同梱 |
| 地方の広告代理店 | 自治体・観光案件の制作パートナー | 入札時の制作実績提供 |

### 6-3. アウトバウンド

- 採用に困っている業種（物流、介護、建設、飲食、警備）で、求人を出し続けている企業をリスト化（Indeed・自社採用ページを見る）
- 「御社の採用ページの内容でAIドラマを1話作ってみました」という**作ってから送る営業**（AI軸だから原価1万円で可能。これは実写専業には真似できない）
- 営業代行の相場・実績: 6ヶ月で36アポ4受注の事例。月商200万を超えたら併用を検討

### 6-4. インバウンド（SEO・料金公開）

- 競合はほぼ全社「ショートドラマ 制作 費用」系の記事で集客している＝効いている
- **競合の多くが料金非公開なので、料金と原価構造を公開する**。「1話単発は受けない理由」「4話108万の中身」を書くと、それ自体が信頼になる
- 記事テーマ: 業種別事例、採用ドラマの費用対効果、AI vs 実写の選び方、AI表記ポリシー

### 6-5. オファー設計

| 段階 | オファー | 狙い |
|---|---|---|
| 入口 | AIトライアル1話 5万円 | 「作ってから送る」と組み合わせ、判断コストを下げる |
| 本命 | 実写4話パック 108万 / AI 6話パック 54万 | 1撮影日でまとめ撮り、シリーズ前提 |
| 継続 | 月額AIライト 38万 / 実写スタンダード 130万 | 月商の柱 |
| アップセル | Spark Ads運用、多言語、ハイブリッド | 単価上げ |

「再生数保証」はしない（GOKKOでも企業案件はバズが1/3）。代わりに「フック3案ABテスト」「視聴維持率レポート」を標準化して**プロセスで信頼を取る**。

## 7. 制作体制とオペレーション

### 7-1. AI制作パイプライン

```
脚本テンプレ（3秒フック / 3人まで / 60〜90秒 / CTA）
  → LLMで下書き → 人が仕上げ（業種の「あるある」精度が命）
  → キャラクターバンク作成（Nano Banana Pro で顔・衣装・年齢の参照画像）
  → シーン生成（Kling 3.0 Omni 主軸、Veo 3.1 を高品質カットに併用）
  → 音声（Kling ネイティブ音声 or ElevenLabs）
  → 編集・テロップ（CapCut / Premiere）
  → QAゲート（不気味の谷チェック、権利チェック、ブランド適合）
  → 納品（本編＋フック3案＋横型）
```

- マルチベンダー前提（Sora 2 APIは2026年9月廃止予定。特定モデル依存は禁止）
- キャラクターバンクはシリーズで再利用 → 2話目以降の原価が下がる
- 1話あたり4〜6時間、1名で月15〜20話

### 7-2. 実写制作フロー

```
ヒアリング（1h、顧客施設で）
  → 脚本4話分（テンプレ、1週間で承認）
  → 俳優手配（俳優プール: 養成所・小劇場・芝居研究会型のコミュニティを自前で作る）
  → 撮影1日（顧客施設、8時間で5〜15シーン=3〜4話）
  → 編集（1話2〜2.5万、外注）
  → 納品・投稿・1ヶ月後レポート
```

- 撮影日単位でキャパ管理（月3日→6日→8日）
- 俳優には「AI学習利用は別同意」を出演契約に明記

### 7-3. 品質KPI（顧客レポートに載せる）

- 3秒視聴維持率（目標60%以上）
- 平均視聴率、完視聴率
- フォロワー純増、プロフィール遷移
- CV（応募数、予約数、問い合わせ）
- フックA/B/Cの勝敗

### 7-4. 体制（12ヶ月目）

| 役割 | 人数 | 形態 |
|---|---|---|
| 代表（営業・プロデュース） | 1 | 本人 |
| 脚本・ディレクター | 1 | 社員 or 固定業務委託 |
| AIオペレーター | 1〜2 | 業務委託 |
| 撮影クルー（監督兼カメラ、録音） | 都度 | 外注 |
| 編集 | 都度 | 外注 |
| 営業アシスタント／運用 | 1 | パート or 業務委託 |

## 9. リスクと対策

| リスク | 兆候 | 対策 |
|---|---|---|
| AI価格崩壊（中国型の量産が国内に波及） | 「AIドラマ3万円」の広告が増える | AI軸の価値を「脚本×運用×権利対応」に置く。生成単体では売らない |
| 炎上・ブランド毀損 | AI感への否定コメント | QAゲート、開示ポリシー、食品・医療・高級はAIを勧めない |
| ツール依存 | APIの廃止・値上げ（Sora 2の例） | マルチベンダー、月次でモデル評価 |
| 実写の稼働ボトルネック | 撮影日が埋まり納期遅延 | 撮影日単位でキャパを公開、外部クルーを2チーム化 |
| 単発依存で月商が乱高下 | スポット比率50%超 | 6ヶ月目以降パック・月額のみ受注 |
| 権利トラブル | 俳優の声・肖像のAI転用 | 出演契約にAI条項、法務省指針に準拠 |
| 大手参入（Minto、AOI等） | 大手がAIドラマの価格を公開 | 中小・地方・採用に集中し、大手が取らない小口を積む |
